# 📝 Quiz Application (Spring Boot)

A web-based quiz application where **admins** can create and manage quizzes, and **test takers** can participate in quizzes if invited.

## 🚀 Features


### **👨‍💼 Admin Features**
- ✅ Login as Admin  
- ✅ Upload questions  
- ✅ Create and manage tests  
- ✅ View all available questions  
- ✅ Invite test takers to a test  

### **🧑‍💻 Test Taker Features**
- ✅ Login as Test Taker  
- ✅ Take a test **only if invited**  
- ✅ Auto-submit test when time expires  
- ✅ View test results
